02 — Overview

Visualizing high-frequency telecommunication in real time.

Callswain AI is a cloud telephony management platform built for modern inbound and outbound support operations. It serves two interconnected audiences: operations managers who need to configure complex Interactive Voice Response (IVR) phone menus without touching XML scripts, and team supervisors who need live visibility into call queues, agent talk times, and audio health across distributed call centers.

03 — The Challenge

Legacy PBX tools are rigid, code-heavy, and blind in emergencies.

Traditional enterprise call centers rely on legacy telecommunication platforms that treat call routing as nested spreadsheets or developer-only code scripts. When unexpected call spikes occur or an office closes for emergencies, updating a phone tree can take hours of engineering coordination. Furthermore, supervisors have no real-time way to detect caller abandonment until post-shift reports are generated hours later.

✕ Legacy Telephony Software

Rigid, Code-Heavy Menus

Opaque configuration and delayed post-call reporting cause high caller drop-off.

  • ✕
    Developer-Only Routing: Changing an IVR branch requires manual XML editing and telecom ticket submissions.

    Lagged Telemetry: Queue spikes and call abandonment are discovered hours after callers hang up in frustration.

04 — Users & Operational Roles

Designed for high-pressure operations commanders and front-line agents.

Call center environments operate under intense temporal pressure. The interface was engineered around the concrete workflows of two core operational personas:

ROLE 01

Call Center Operations Supervisor

Builds and iterates IVR phone trees, monitors queue thresholds, and manages real-time agent capacity across departments.

ROLE 02

Front-Line Support Agent

Receives incoming routed calls, references caller context cards, logs post-call wrap-up dispositions, and toggles availability status.

ROLE 03

Quality Assurance Auditor

Listens to recorded call archives, inspects duration benchmarks, and evaluates handling compliance using standardized scorecards.

ROLE 04

Telephony Infrastructure Admin

Manages phone number allocations, WebRTC carrier trunking, and emergency forwarding numbers during carrier outages.

05 — Product Workflow

The Telephony Lifecycle: From Inbound Dial to Wrap-Up Disposition

How an inbound telephone call moves through Callswain's interface architecture:

PHASE 01 — ENTRY

Carrier Ingest

Caller dials inbound DID number. System immediately parses caller ID and checks active business-hour filters.

PHASE 02 — ACTION

Visual IVR Branching

Caller hears synthesized voice prompt and enters DTMF keypad options. System traverses configured visual node tree.

PHASE 03 — DECISION

Intelligent Queue Routing

Call reaches target department queue. Engine routes to next available agent based on idle duration and skill tags.

PHASE 04 — COMPLETION

Live Call & Wrap-Up

Agent accepts call with real-time waveform audio. Upon hang-up, mandatory wrap-up timer records disposition tag.

07 — Key UX Decisions

Designing for high-pressure, zero-error telecommunication environments.

Every design decision in Callswain AI was driven by the reality that seconds matter when managing live phone queues:

INTERACTION DESIGN

Visual Node Canvas over Matrix Tables

Phone trees are inherently spatial graphs, not flat tables. By moving IVR design to a visual node canvas, supervisors can immediately trace the caller's mental path ("If caller presses 1 → go to Sales → if wait time > 3 mins → route to Overflow Voicemail").

TELEMETRY ERGONOMICS

Waveform Glancing over Audio Tapping

Supervisors managing 40+ agents cannot listen to every call simultaneously. I integrated mini waveform animations into each active call card. A flat line signals awkward silence or an unmuted hold; rhythmic waves signal an active dialogue.

ERROR PREVENTION

Dead-End Branch Detection

A common failure in legacy telephony is publishing an IVR branch that terminates without an action, hanging up on callers. The canvas runs real-time connectivity validation, highlighting unconnected ports in warning amber before publication.

COLOR SEMANTICS

High-Visibility Agent States

Using Callswain's brand orange for interactive triggers, paired with emerald green for ready agents, deep blue for active calls, and muted charcoal for offline desks—ensuring supervisors can scan room status in a split second.

09 — Design System

A high-contrast visual language built for 24/7 command centers.

Call centers often run in low-light environments. The design system prioritizes contrast, legible numeric telemetry, and durable visual tokens:

COLOR SYSTEM

Dark Zinc + Callswain Orange

Deep charcoal surfaces (`#18181b` / `#09090b`) reduce eye fatigue during long shifts, while vibrant brand orange (`#FF6B00`) highlights primary actions, active audio waveforms, and important queue alerts.

TYPOGRAPHY SYSTEM

Plus Jakarta Sans & Monospace Timers

Plus Jakarta Sans provides high clarity for agent names and IVR prompt text, while monospaced numerical figures prevent layout jitter as live call second-counters tick in real time.

11 — Designer Reflection

What this project taught me as a product designer.

"Designing for voice telephony taught me the critical difference between static data and live operational state. In a call center, information is constantly decaying: a caller waiting 30 seconds is normal, but a caller waiting 3 minutes is an operational emergency. UI elements can't just display numbers—they have to visually convey temporal urgency and give operators immediate levers to intervene."

— S M Roqunuzzaman · UI/UX Designer
