02 — Overview

Democratizing conversational voice engineering for non-developers.

Voqal AI is a cloud SaaS platform that allows businesses to build, test, and deploy intelligent conversational voice agents without writing custom backend code. Designed for Betopia Group, the product spans the entire voice development lifecycle: from drafting persona prompts and picking synthetic voice models to running live in-browser test phone calls, reviewing transcript logs, and managing team billing across international operations.

03 — The Challenge

Bridging high-latency AI parameters with intuitive interface design.

Configuring conversational speech AI involves technical complexities that overwhelm standard business operators: model temperature, voice synthesis models, time-to-first-byte (TTFB) latencies, and knowledge base document indexing. In existing developer tools, creators had to edit JSON payloads and use external telephone lines to test if an agent sounded natural, resulting in slow feedback loops and frustrating setup experiences.

✕ Fragmented Developer Tools

Code-Heavy Configuration & Blind Testing

Users juggle command-line scripts and telephony providers just to test a single prompt adjustment.

  • ✕
    Overwhelming Parameter Dumps: Exposing raw LLM weights, sampling rates, and token limits confuses non-technical operators.
  • ✕
    External Testing Friction: Creators had to deploy code to a live server and dial a physical telephone to hear the voice agent.
  • ✕
    Opaque Call Failures: When an agent pauses or gives a robotic reply, traditional logs show raw error codes without timestamped transcripts.
✓ Voqal Integrated Studio

Guided Wizard & In-Browser Simulator

An interactive studio unifying prompt authoring, voice auditioning, and real-time WebRTC simulation.

  • ✓
    Guided 3-Step Wizard: Step-by-step progressive disclosure isolating identity, knowledge, and telephony settings.
  • ✓
    Live In-Browser Simulator: Interactive telephone handset interface allowing creators to test conversations instantly with one click.
  • ✓
    Dual-Channel Transcripts: Synchronized audio playback highlighting agent vs. caller speech bubbles with confidence scores.
04 — Users & Operational Roles

Designed for creators, analysts, and enterprise administrators.

The platform serves three specialized user groups across an organization's voice deployment journey:

ROLE 01

Voice Prompt Creator

Defines agent persona, writes system prompts, selects voice timber, and configures fallback knowledge base documents.

ROLE 02

Conversation Analyst

Inspects historical call logs, reads verbatim transcripts, flags misheard caller intents, and benchmarks conversation completion.

ROLE 03

Operations Super Admin

Oversees multi-tenant company accounts, provisions outbound phone numbers, and manages telephony credit usage meters.

ROLE 04

Department Manager

Assigns specific voice agents to customer support queues, sets business operating hours, and monitors caller satisfaction ratings.

05 — Product Workflow

The Guided 3-Step Agent Creation & Deployment Flow

To eliminate setup fatigue, I structured agent creation into a focused, progressive journey:

STEP 01 — IDENTITY

Persona & Voice Selection

Name the agent, select target primary language, audition sample voice clips, and calibrate pitch and speaking speed.

STEP 02 — KNOWLEDGE

Instructions & Guardrails

Define conversational mission, enter fallback scripts, and upload company reference PDFs for automated retrieval.

STEP 03 — TESTING

Interactive Simulation

Launch an in-browser WebRTC call with the live agent. Speak naturally to test interruptions, pauses, and latency.

STEP 04 — DEPLOYMENT

Phone Number Assignment

Link the tested agent to an inbound DID phone number or web chat widget with active telemetry monitoring.

07 — Key UX Decisions

Designing for conversational repair and rapid iteration.

AI voice interfaces have unique friction points. I established specific design solutions to make testing and refinement seamless:

SPLIT-SCREEN ERGONOMICS

Zero-Context-Switch Testing

In standard tools, testing a prompt adjustment required navigating to a different page or opening a modal. By embedding a live WebRTC audio handset directly on the right side of the prompt editor, creators make a tweak and test it within two seconds.

TRANSCRIPT USABILITY

Click-to-Seek Audio Dialogue

Call center managers reviewing a 10-minute call don't want to listen to the whole recording. Each spoken transcript bubble is tied to audio timestamps: clicking the user's complaint immediately jumps playback to that moment.

PROGRESSIVE DISCLOSURE

Hiding Machine Learning Jargon

Technical terms like "top_p", "frequency_penalty", and "chunk_overlap" were moved into an "Advanced Model Engineering" collapsible drawer, while common business controls (Voice Timber, Tone, and Core Instructions) remain front and center.

LATENCY TRANSPARENCY

Visual Audio Inflection Meters

Voice agents feel robotic if they pause too long before speaking. I designed real-time synthesis badges that clearly show when the agent is "Listening", "Synthesizing", or "Speaking", helping designers diagnose conversational lag.

11 — Designer Reflection

What this project taught me as a product designer.

"Designing for conversational AI voice agents made me realize that latency is a primary UX concern, not just an engineering metric. When an AI speaks, even a half-second pause feels awkward to a human caller. The interface had to make latency visible and manageable to creators so they could design prompts that set expectations, acknowledge input immediately, and keep conversations feeling natural."
